Les méthodes ensemblistes en Machine Learning

Réalisé par : Badry Ibrahym · 12/12/2026

Introduction et problématique

Pourquoi combiner plusieurs modèles ?

Prérequis

Apprentissage supervisé, classification et régression, SVM, arbres de décision (DT), réseaux de neurones, métriques d’évaluation.

Problématique

Comment les prédictions correctes d’un modèle peuvent-elles compenser les erreurs d’un autre ?

Objectif

Améliorer la performance et la robustesse.

Réflexion : radiographies du thorax (Covid-19)

2 classes : Covid et Normal · 3 modèles entraînés · jeu de validation de 10 images.

Les méthodes ensemblistes

Ensemble Learning : combiner les résultats de plusieurs modèles

À utiliser si

Données complexes et hétérogènes · réduction de la variance.

À éviter si

Données simples et homogènes · ressources limitées · besoin d’interprétabilité.

Bagging

Bootstrap Aggregating : même algorithme, sous-ensembles aléatoires, agrégation

Bootstrap : chaque modèle est entraîné sur un sous-ensemble aléatoire.
Agrégation : vote majoritaire (moyenne pour la régression). Exemple : Random Forest.
for i in range(B):
    S_i = bootstrap(train)        # tirage avec remise
    model[i] = DecisionTree().fit(S_i)
y = majority_vote([m.predict(x) for m in model])

Boosting

Séquentiel : chaque modèle corrige les erreurs du précédent

Le poids des fausses prédictions augmente à chaque itération

Modèles faibles (arbres de décision). Exemples : AdaBoost, Gradient Boosting, XGBoost.

w = [1/N] * N
for t in range(T):
    h_t = WeakLearner().fit(X, y, sample_weight=w)
    err = weighted_error(h_t, X, y, w)
    w[wrong] *= alpha(err)         # ↑ erreurs

Stacking

Un méta-modèle apprend à combiner les prédictions

P = [m.fit(X, y).predict(X) for m in base_models]  # SVM, KNN, DT
meta = LogisticRegression().fit(stack(P), y)
y_final = meta.predict(stack([m.predict(x) for m in base_models]))

Résultats

Étude comparative : accuracy de chaque implémentation

Analyse. Le Bagging avec arbre de décision obtient la meilleure performance (99 %). Vote majoritaire, vote pondéré, KNN, SVM et stacking atteignent 96 à 98 %. Le choix dépend du problème et du compromis précision / complexité.

Conclusion

L’ensemble learning améliore la performance en combinant plusieurs modèles : les faiblesses de chacun sont compensées, la prédiction est plus robuste.
  • Vote : agrège les prédictions (majoritaire, pondéré, moyenne).
  • Bagging : modèles indépendants sur des sous-ensembles aléatoires.
  • Boosting : modèles séquentiels corrigeant les erreurs.
  • Stacking : méta-modèle de niveau supérieur.
